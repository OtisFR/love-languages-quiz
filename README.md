# 愛之語線上測驗｜原始碼

這是單頁、無須安裝套件的互動測驗。將 `index.html` 放在一般靜態網站空間即可使用，也可以直接用瀏覽器開啟。

## 使用技術

- HTML5：頁面結構與作答介面。
- CSS3：自適應排版、顏色、進度條與結果卡片。
- 原生 JavaScript：十題二選一、上一題／下一題、A–E 五類計分、並列最高分、結果與對應練習的動態顯示。
- 無前端框架、無外部套件、無伺服器程式或資料庫。

## 如何使用

1. 解壓縮後，用瀏覽器開啟 `index.html` 即可試用。
2. 若要讓其他人從網址開啟，把 `index.html` 上傳到支援靜態網頁的主機。
3. 修改題目：編輯檔案內 `<script>` 的 `items` 陣列；每題兩個選項各有一個 A–E 分類。
4. 修改結果與練習：編輯同一段程式中的 `types` 物件，包含 `name`、`desc`、`practice` 等文字。
5. 修改頁面文字及顏色：編輯 HTML 與 `<style>` 區塊。

## 計分方式

每題擇一，共 10 題。被選選項所屬的類別加 1 分；A–E 每類在題目中各出現 4 次，因此各類分數範圍是 0–4。結果頁顯示五類分數，最高分可並列，並依最高分類別顯示相應的回家練習。

## 資料處理

本版本只在瀏覽器目前頁面記住作答進度；重新整理後會重置。程式不會將答案送到伺服器，也不會蒐集姓名或保存測驗紀錄。
